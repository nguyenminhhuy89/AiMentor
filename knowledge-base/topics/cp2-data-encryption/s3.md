# CP2 · S3

> Summary: 20 CP2 questions on S3 (6 easy, 10 medium, 4 hard) with answers and explanations.

## Context
Part of the CP2 Data & Encryption bank. Exam questions marked ★ are in the current exam (seed exam-v1-CP2).

## Questions

### CP2-Q041 · Easy
What is Amazon S3?

- A. A message queue
- B. Object storage for files (objects) in buckets
- C. A container registry
- D. A relational database

**Answer: B** — Invoices are stored in S3.

### CP2-Q042 · Easy
What uniquely identifies an object in S3?

- A. Bucket name plus object key
- B. The object's size
- C. The upload date
- D. Only the file name

**Answer: A** — e.g. s3://orders-invoices/2026/12/ord_1.pdf.

### CP2-Q043 · Easy
Which API uploads an object?

- A. HeadBucket
- B. PutObject
- C. ListBuckets
- D. GetObject

**Answer: B** — Large files use multipart upload.

### CP2-Q044 · Easy ★
What is a presigned URL?

- A. A time-limited URL that grants access to a specific object without AWS credentials
- B. A permanent public link
- C. A CloudFront domain
- D. A bucket policy

**Answer: A** — Generated with the PresignClient.

### CP2-Q045 · Medium
What should be set on a presigned GET URL for invoices?

- A. No expiry
- B. A short expiry (e.g. 15 minutes)
- C. Public-read ACL
- D. One year expiry

**Answer: B** — Limit exposure if the URL leaks.

### CP2-Q046 · Medium
What does Block Public Access do?

- A. Blocks all IAM users
- B. Prevents buckets/objects from being made public by ACLs or policies
- C. Disables encryption
- D. Stops presigned URLs

**Answer: B** — Keep it on for every bucket.

### CP2-Q047 · Medium
Which server-side encryption option uses a customer managed KMS key?

- A. SSE-C with no key
- B. No encryption
- C. SSE-KMS
- D. SSE-S3

**Answer: C** — SSE-KMS gives key policy control and CloudTrail auditing.

### CP2-Q048 · Medium
Bucket names must be…

- A. Uppercase
- B. Unique per region only
- C. Unique per account only
- D. Globally unique across all AWS accounts

**Answer: D** — Use a prefix with team and env.

### CP2-Q049 · Medium
What is S3 versioning for?

- A. Keeping previous versions of objects to recover from overwrites/deletes
- B. Version control for Go code
- C. Versioning the API
- D. Faster uploads

**Answer: A** — Pair with lifecycle rules.

### CP2-Q050 · Medium ★
What is a lifecycle rule?

- A. An IAM rule
- B. A Kong route
- C. A rule to transition or expire objects after a time
- D. A CloudWatch alarm

**Answer: C** — e.g. move invoices to Glacier after 1 year.

### CP2-Q051 · Medium
How should the service store the invoice location?

- A. Store the presigned URL permanently
- B. Store the bucket/key in the order record, not a presigned URL
- C. Store the file bytes in DynamoDB
- D. Store nothing

**Answer: B** — Generate fresh presigned URLs on demand.

### CP2-Q052 · Hard
Which permission is needed to generate a working presigned GET URL?

- A. No permission at all
- B. The signer's role must have s3:GetObject on the object
- C. kms:CreateKey
- D. s3:* on *

**Answer: B** — The URL acts with the signer's permissions.

### CP2-Q053 · Hard ★
A presigned URL for an SSE-KMS object fails with AccessDenied. Likely cause?

- A. S3 does not support KMS
- B. The object key has slashes
- C. The bucket is too large
- D. The signer lacks kms:Decrypt on the key

**Answer: D** — KMS permissions apply to encrypted objects.

### CP2-Q054 · Easy
What does ListObjectsV2 return?

- A. Keys of objects in a bucket, optionally filtered by prefix
- B. All buckets in all accounts
- C. The bucket policy
- D. Object contents

**Answer: A** — Paginate for large buckets.

### CP2-Q055 · Medium ★
Which content type should be set when uploading a PDF invoice?

- A. application/pdf
- B. image/png
- C. application/json
- D. text/plain

**Answer: A** — Correct Content-Type makes downloads behave.

### CP2-Q056 · Hard
How do you prevent the service from overwriting an existing invoice key?

- A. Use a conditional write (If-None-Match: *) or unique keys per invoice
- B. Use lowercase keys
- C. Use GetObject first without checks
- D. Make the bucket public

**Answer: A** — Unique keys/conditions avoid races.

### CP2-Q057 · Medium
What is the S3 equivalent of a folder?

- A. A sub-bucket
- B. A volume
- C. A key prefix such as 2026/12/
- D. A directory object type

**Answer: C** — S3 is flat; prefixes organize keys.

### CP2-Q058 · Hard
What is a good test approach for S3 code in CI?

- A. Skip S3 tests
- B. Use the production bucket
- C. Test only manually
- D. Interface-based mocks for unit tests and LocalStack for integration tests

**Answer: D** — No real cloud calls in unit tests.

### CP2-Q059 · Easy ★
Which service hosts the capstone's invoice files?

- A. Amazon S3
- B. AWS Lambda
- C. Amazon RDS
- D. Amazon SQS

**Answer: A** — Invoices are objects.

### CP2-Q060 · Medium
What is the maximum single PutObject upload size?

- A. 5 GB (larger requires multipart upload)
- B. 5 TB in a single PUT
- C. 5 MB
- D. Unlimited

**Answer: A** — Objects can be up to 5 TB via multipart.
